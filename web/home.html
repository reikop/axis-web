AXIS Web Reconstruction

A browser rebuild of the 2005 OpenGL action game AXIS, decoded directly from a legally-owned copy. Every file format — archives, maps, 3D meshes and textures — has been reverse-engineered and renders here from your own game data.

Where this is. The reverse-engineering and asset pipeline are complete — maps, models and textures all render above from your own install — and the multiplayer transport works: run node server/relay.js, open the Map Viewer in two browsers, hit Connect, and you walk a shared map and see each other's avatars (the game's real 64-byte packet protocol over WebSocket). What remains is the rest of the interactive runtime — texturing meshes (needs dynamic capture), skeletal animation, full combat/item logic, and the Emscripten/WASM client build. Full notes live in docs/SPEC.md.
